Features

Boring on purpose. Just plain Ruby.

No magic, no native extensions, no sprawling dependency tree — just readable stdlib Ruby that does one job and does it reliably.

Pure Ruby

Built on blocking I/O and threads. No C extensions, no native bindings — code you can read end to end.

threads + I/O
Zero dependencies

Ruby stdlib only — nothing to audit, nothing to keep up to date. Runs on Ruby 2.7+.

0 gems
TLS by default

The client ↔ server link is encrypted and verified against the system CA store out of the box.

VERIFY_PEER
Auto-reconnect

Drops are handled with exponential backoff, and a saved token restores the very same subdomain.

backoff 1→30s
Unique URL each run

Every session gets a fresh random subdomain on tunnel-rb.dev — share it and revoke it freely.

random subdomain
No server setup

Uses the hosted relay by default. Want a private instance? Self-host the server in one command.

hosted relay
